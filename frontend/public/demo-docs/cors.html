跨域与 Cookie 排查

静态演示资料：引用和相似度为预录展示，不是实时检索或效果评测。

Origin 包含协议、域名与端口。携带 Cookie 的跨域请求应显式允许可信 Origin，不能使用通配符；核对 OPTIONS 预检、允许的方法和请求头，以及 Cookie 的 Secure 与 SameSite 属性。

在浏览器中核对

  1. 从 Network 面板获取实际 Origin。
  2. 查看 OPTIONS 的状态码和响应头。
  3. 检查实际请求是否带上 Cookie。
  4. 结合后端配置验证候选原因。

跨域提示不能直接证明后端不可用，也不应通过放开所有来源来替代排查。
